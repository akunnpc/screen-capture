# Referensi tangkapan layar

Kosong, sengaja. Recon ini tidak menyimpan gambar apa pun dari aplikasi asli, dan APK tidak dibongkar.

Kalau Anda ingin layar Android (S01 sampai S20) dikonfirmasi, ambil tangkapan layar dari HP Anda sendiri,
dari aplikasi yang Anda instal sendiri, lalu taruh di folder ini dengan nama sesuai ID layar (misalnya `S05.png`).
Tangkapan layar hanya untuk perbandingan tata letak dan tidak pernah dimasukkan ke klon.
